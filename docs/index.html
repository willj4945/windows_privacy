Windows 11 Privacy Toolkit

A free, open-source GUI utility that helps you harden privacy and security on Windows 11 — no coding required, fully reversible.

⬇ Download for Windows View on GitHub

Windows 11 (build 22000+) · Administrator privileges required · MIT licensed

What it does

Eighteen individual settings across four categories, applied selectively via checkboxes — nothing runs unless you tell it to.

🔒 Privacy hardening

Telemetry, advertising ID, location, activity history, Recall, Cortana & Bing search, suggested content, lock screen ads, tailored experiences.

🧩 Services

OneDrive sync, background apps, Edge sync & telemetry.

🛡️ Security hardening

Disable SMBv1, enable Network Protection and Controlled Folder Access, enforce UAC, block AutoRun.

🗑️ Debloating

Remove common bloatware or all non-essential Microsoft Store apps, with a full preview before anything is removed.

📊 Privacy score

Live scan of your current system against every setting above, with a percentage score that updates as you apply changes.

♻️ Safe & reversible

Creates a system restore point before applying changes, plus a one-click Restore Defaults.

Security & trust

This tool runs as Administrator and changes real system settings — you shouldn't have to just take our word for what's inside it.

⚠️ Current releases are unsigned. Windows SmartScreen may warn that the download is from an unrecognized publisher. Code signing is on the roadmap — see the sponsorship note below — but every release ships with a checksum so you can verify the file wasn't tampered with in transit.

Every .exe is built directly from this public source code by an automated GitHub Actions workflow (not compiled on a personal machine), and every release includes a SHA256SUMS.txt file. To verify your download, open PowerShell and run:

Get-FileHash .\Win11PrivacyToolkit.exe -Algorithm SHA256

...then compare the output to the checksum published on the Releases page.

  • 100% open source — read every line before you run it
  • Built and published by a public, auditable GitHub Actions workflow
  • No network calls, no telemetry of its own, no bundled third-party software
  • Every applied change is logged to a local text file
  • Vulnerability reports handled per our security policy

Support the project

This is a solo, spare-time open-source project. The biggest thing standing between this tool and a fully code-signed release (no more SmartScreen warnings) is the ongoing cost of a code-signing certificate.

Sponsorship isn't live yet, but it's coming — the first goal is funding code signing so every release is trusted by Windows out of the box.
